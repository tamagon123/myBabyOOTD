14. 主要フローまとめ（シーケンス風）
================================================================================

【ログインフロー】
1. アプリ起動 → myBabyCodeApp.init() → Firebase.configure()
2. AuthViewModel.initialize() → Auth状態確認
3. 未ログイン → SplashView → AuthView
4. ログイン処理（Email/Google/Apple）→ Firestore users確認
5. 新規 → is_profile_complete=false → ProfileSetupView
6. 既存 → is_profile_complete=true → MainTabView

【タイムライン表示フロー】
1. HomeView.task → PostsViewModel.fetchPosts()
2. Firestore postsクエリ（is_hidden=false, orderBy created_at desc）
3. enrichWithPosterInfo() → 投稿者アバター・名前を並列取得
4. HomeViewにposts配列反映 → PostCardView生成
5. 最後の要素onAppear → fetchMorePosts() ページネーション
6. Pull-to-refresh → fetchPosts() + fetchLikedPosts()

【投稿作成フロー】
1. MainTabView +ボタン → NewPostView（sheet）
2. 写真選択（カメラ/ライブラリ）→ ImagePickerView → PhotoEditorView（任意）
3. アイテム入力 → ItemEntryRow（ブランド・サイズ）
4. アイテムタグ付け → tagPlacementView（タップで比率座標）
5. 天気自動取得 → WeatherService.fetch(regionCode)
6. 投稿ボタン → submitPost() → uploadPost()
   - resizeImage() → stripEXIF() → Storageアップロード
   - Post作成 → Firestore保存 → itemsサブコレクション保存
   - item_tags保存
7. 成功 → fetchPosts() → dismiss()

【いいねフロー】
1. PostCardView ハートボタンタップ → onLike()
2. PostsViewModel.toggleLike(post)
3. likes/{uid}_{postId} 作成/削除
4. posts/{postId}.likes_count increment/decrement
5. ローカル likedPostIds / posts配列更新

【通報フロー】
1. PostCardView 通報ボタン → onReport()
2. PostsViewModel.report(post)
3. reports/{uid}_{postId} 作成
4. posts/{postId}.reports_count increment
5. reports_count >= 5 → is_hidden=true → posts配列から削除

【フォローフロー】
1. ProfileView（他ユーザ）→ フォローするボタン
2. ProfileView.toggleFollow()
3. follows/{myId}_{userId} 作成/削除
4. users/{userId}.followers_count increment/decrement

【検索フロー】
1. SearchView → フィルタ条件設定
2. 検索ボタン → executeSearch()
3. Firestore複合クエリ（region/gender/weather/temp_category）
4. クライアント側でbrandQueryフィルタ
5. PostCardViewリスト表示

【アカウント削除フロー】
1. SettingsView → アカウント削除
2. 再認証ダイアログ（Emailパスワード / Google再ログイン）
3. AuthViewModel.deleteAccount()
4. users/{uid} 削除 → posts削除 → likes削除 → follows削除
5. Firebase Auth.user.delete()
6. isSignedIn=false → AuthViewへ遷移
