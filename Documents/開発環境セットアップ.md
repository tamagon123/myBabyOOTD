# 開発環境セットアップ手順書

> 本プロジェクトの開発環境構築、AdMob導入、StoreKit（アプリ内購入）設定の総合手順書です。
> 作業が終わったら `[ ]` を `[x]` に変えてください。

---

## STEP 1 — Firebase プロジェクト作成

### 1-1. Firebaseコンソールにアクセス
- [ ] ブラウザで https://console.firebase.google.com を開く
- [ ] Googleアカウントでログイン

### 1-2. 新しいプロジェクトを作成
- [ ] 「プロジェクトを作成」をクリック
- [ ] プロジェクト名に「myBabyCode」と入力 → 続行
- [ ] Google アナリティクスは「今は必要ない」でOK → プロジェクトを作成

### 1-3. iOSアプリを登録
- [ ] プロジェクトのホーム画面で「iOS+」アイコンをクリック
- [ ] 「Appleバンドル ID」に Xcode の Bundle Identifier を入力する
      ※ Xcode で確認する方法：
        myBabyCode.xcodeproj をクリック → ターゲット「myBabyCode」→
        「Signing & Capabilities」タブ → Bundle Identifier の値をコピー
        （例: com.tamaki.myBabyCode）
- [ ] アプリのニックネーム: myBabyCode（任意）
- [ ] 「アプリを登録」をクリック

### 1-4. GoogleService-Info.plist をダウンロード
- [ ] 「GoogleService-Info.plist をダウンロード」をクリックしてファイルを保存
- [ ] Xcode を開く
- [ ] プロジェクトナビゲータ（左パネル）で「myBabyCode」フォルダを右クリック
      →「Add Files to "myBabyCode"...」を選択
- [ ] ダウンロードした GoogleService-Info.plist を選択
- [ ] 「Add to targets: myBabyCode」にチェックが入っていることを確認 → Add
- [ ] Firebase コンソールに戻り「次へ」→「次へ」→「コンソールに進む」

---

## STEP 2 — Firebase SDK を Xcode に追加（SPM）

### 2-1. パッケージを追加する
- [ ] Xcode のメニューバー「File」→「Add Package Dependencies...」を選択
- [ ] 検索バーに以下のURLを貼り付けてEnter:
      https://github.com/firebase/firebase-ios-sdk.git
- [ ] バージョンは「Up to Next Major Version」のまま「Add Package」をクリック
- [ ] 少し待つとパッケージ選択画面が出る

### 2-2. 必要なライブラリを選択
- [ ] 以下の3つにチェックを入れる（それ以外はチェック不要）:
      ✅ FirebaseAuth
      ✅ FirebaseFirestore
      ✅ FirebaseStorage
      （FirebaseFirestoreSwift は不要 → Firebase 11以降で FirebaseFirestore に統合済み）
- [ ] 「Add Package」をクリック（数分かかる場合あり）

### 2-3. AdMob SDK も追加
- [ ] 再度「File」→「Add Package Dependencies...」
- [ ] 以下のURLを貼り付けてEnter:
      https://github.com/googleads/swift-package-manager-google-mobile-ads.git
- [ ] 「Add Package」→「GoogleMobileAds」にチェック →「Add Package」

---

## STEP 3 — Firebase の各機能を有効化（コンソール）

### 3-1. Authentication（認証）を有効化
- [ ] Firebase コンソール左メニュー「構築」→「Authentication」→「始める」
- [ ] 「Sign-in method」タブを選択
- [ ] 「Apple」をクリック → 「有効にする」トグルをON → 「保存」
- [ ] 「メール / パスワード」もクリック → 「有効にする」トグルをON（上段のみ）→「保存」

### 3-2. Firestore Database を作成
- [ ] Firebase コンソール左メニュー「構築」→「Firestore Database」→「データベースの作成」
- [ ] 「本番環境モード」を選択 → 「次へ」
- [ ] ロケーション: 「asia-northeast1（東京）」を選択 → 「有効にする」

### 3-2-b. Firestore 複合インデックスを作成（必須）

> インデックスがないと投稿一覧・マイページが表示されません。

- [ ] Firebase コンソール → Firestore → 「インデックス」タブ →「複合インデックスを作成」

**インデックス①（タイムライン用）**

| コレクション | フィールド | 順序 |
|---|---|---|
| posts | is_hidden | 昇順 |
| posts | created_at | 降順 |

- [ ] 上記を入力して「保存」（作成に数分かかる）

**インデックス②（マイページ用）**

| コレクション | フィールド | 順序 |
|---|---|---|
| posts | user_id | 昇順 |
| posts | created_at | 降順 |

- [ ] 上記を入力して「保存」（作成に数分かかる）

> ※ 作成中は「構築中...」と表示されます。「有効」になるまで待ってからアプリを再起動してください。

### 3-3. Firestore セキュリティルールを設定
- [ ] Firestore の「ルール」タブをクリック
- [ ] 既存のルールを全部消して以下を貼り付ける:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth.uid == userId;
    }
    match /posts/{postId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null;
      allow update: if request.auth != null;
    }
    match /follows/{followId} {
      allow read, write: if request.auth != null;
    }
    match /likes/{likeId} {
      allow read, write: if request.auth != null;
    }
    match /reports/{reportId} {
      allow read, write: if request.auth != null;
    }
  }
}
```

- [ ] 「公開」をクリック

### 3-4. Storage（写真保存）を有効化
- [ ] Firebase コンソール左メニュー「構築」→「Storage」→「始める」
- [ ] 「本番環境モードで開始」→「次へ」
- [ ] ロケーション: 「asia-northeast1」→ 「完了」
- [ ] 「ルール」タブをクリックし、以下に書き換えて「公開」:

```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /posts/{allPaths=**} {
      allow read: if request.auth != null;
      allow write: if request.auth != null
                   && request.resource.size < 10 * 1024 * 1024;
    }
  }
}
```

## STEP 4 — Apple Sign In への移行（リリース直前に実施）

> Apple Developer Program（年額約13,800円）加入後に実施してください。
> https://developer.apple.com/programs/

### 4-1. Xcode で Capability を追加
- [ ] Xcode でプロジェクト（左パネルの一番上のファイル）をクリック
- [ ] 中央パネルでターゲット「myBabyCode」を選択
- [ ] 「Signing & Capabilities」タブをクリック
- [ ] 左上の「＋ Capability」ボタンをクリック
- [ ] 検索ボックスに「Sign In with Apple」と入力 → ダブルクリックで追加
- [ ] 「Sign In with Apple」の行が追加されればOK

### 4-2. Apple Developer Console で設定
- [ ] https://developer.apple.com/account を開く
- [ ] 「Certificates, Identifiers & Profiles」→「Identifiers」
- [ ] Bundle ID（例: com.tamaki.myBabyCode）をクリック
- [ ] 「Sign In with Apple」にチェックを入れる → 「Save」

### 4-3. Firebase に Apple の設定を登録
- [ ] https://developer.apple.com/account → 「Keys」→「+」ボタン
- [ ] Key Name: 「myBabyCode Apple Key」など任意
- [ ] 「Sign In with Apple」にチェック → Configure → Primary App ID を選択 → Save
- [ ] 「Download」でキーファイル（.p8）をダウンロード（1回しかできないので保管）
- [ ] Team ID（画面右上に表示される10桁の英数字）をメモ
- [ ] Key ID（ダウンロード直前の画面に表示）をメモ
- [ ] Firebase コンソール → Authentication → Sign-in method → Apple
      →「Apple チームID」「キーID」「p8ファイル」を入力して「保存」

### 4-4. コードをApple Sign Inに切り替える
- [ ] AuthViewModel.swift を Apple Sign In 版に差し替え（開発者に依頼）
- [ ] AuthView.swift を Apple Sign In ボタン版に差し替え（開発者に依頼）

## STEP 5 — Google AdMob（広告）の設定

### 5-1. AdMob アカウント作成
- [ ] https://admob.google.com を開く
- [ ] Googleアカウントでログイン →「AdMobを開始」
- [ ] 国・タイムゾーン・通貨を設定（日本 / JST / JPY）→ 登録完了

### 5-2. アプリを AdMob に登録
- [ ] AdMob コンソール「アプリ」→「アプリを追加」
- [ ] プラットフォーム: 「iOS」を選択
- [ ] 「アプリはアプリストアに掲載されていますか？」→「いいえ」
- [ ] アプリ名: 「myBabyCode」→「追加」
- [ ] 「アプリID」（ca-app-pub-XXXXXX~XXXXXXXXXX 形式）をメモ

### 5-3. 広告ユニットを作成
- [ ] 「広告ユニット」→「広告ユニットを作成」
- [ ] 広告フォーマット: 「バナー」を選択
- [ ] 広告ユニット名: 「ホーム画面バナー」→「広告ユニットを作成」
- [ ] 「広告ユニットID」（ca-app-pub-XXXXXX/XXXXXXXXXX 形式）をメモ

### 5-4. Info.plist に AdMob アプリID を登録
- [ ] Xcode 左パネルで「myBabyCode」フォルダ内の「Info.plist」を開く
- [ ] 「＋」ボタンで新しいキーを追加:
      Key:   GADApplicationIdentifier
      Type:  String
      Value: ca-app-pub-XXXXXX~XXXXXXXXXX（メモしたアプリID）
- [ ] 追加で以下も設定:

```xml
<key>NSUserTrackingUsageDescription</key>
<string>広告をパーソナライズするために使用します。許可しない場合も広告は表示されますが、関連性が低くなる場合があります。</string>
<key>SKAdNetworkItems</key>
<array>
  <dict>
    <key>SKAdNetworkIdentifier</key>
    <string>cstr6suwn9.skadnetwork</string>
  </dict>
</array>
```

### 5-5. AdBannerView.swift の広告ユニットIDを設定
- [ ] `myBabyCode/Views/Ads/AdBannerView.swift` を開く
- [ ] `AdConfig.bannerAdUnitId` を本番IDに変更:

```swift
static let bannerAdUnitId: String = "ca-app-pub-XXXXXX/XXXXXXXXXX"
```

> **重要**: App Store 審査時にテスト広告IDのままだとリジェクトされます。必ず本番IDに変更してください。
> 開発中は以下のテストIDを使用できます:
> - テスト用アプリID: ca-app-pub-3940256099942544~1458002511
> - テスト用バナーID: ca-app-pub-3940256099942544/2435281174

## STEP 6 — StoreKit 2（アプリ内購入）の設定

### 6-1. App Store Connect で商品を作成
- [ ] [App Store Connect](https://appstoreconnect.apple.com/) にログイン
- [ ] **アプリ** → 対象アプリを選択
- [ ] 左メニュー → **収益化** → **App内購入** →「＋」をクリック
- [ ] 種類: **非消費型** を選択（買い切り型）
- [ ] 参照名: `プレミアムプラン`
- [ ] 製品ID: `com.tamagon.Nanikiru.premium`
- [ ] 価格を設定（例: 日本 ¥490）
- [ ] 表示名・説明文を各言語で入力
- [ ] スクリーンショットをアップロード
- [ ] 「保存」→「提出準備完了」

### 6-2. コード内の Product ID を確認
- [ ] `myBabyCode/Services/SubscriptionManager.swift` を開く
- [ ] `PremiumConfig.productId` が App Store Connect の製品IDと一致しているか確認

```swift
private enum PremiumConfig {
    static let productId: String = "com.tamagon.Nanikiru.premium"
}
```

### 6-3. シミュレータテスト用の StoreKit Configuration File（任意）
- [ ] Xcode → **File → New → File...**
- [ ] **StoreKit Configuration File** を選択 → **Next**
- [ ] ファイル名: `Products.storekit` → **Create**
- [ ] Default Storefront: Japan
- [ ] Add New In-App Purchase:
  - Reference Name: `プレミアムプラン`
  - Product ID: `com.tamagon.Nanikiru.premium`
  - Type: Non-Consumable
  - Price: JPY 490
- [ ] **Cmd + S** で保存
- [ ] Xcode → **Product → Scheme → Edit Scheme...** → Run → Options
- [ ] **StoreKit Configuration**: `Products.storekit` を選択
