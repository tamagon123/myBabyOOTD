# AdMob app-ads.txt 完了確認チェックリスト

## 前提条件

- AdMob アカウントにログインできること（https://admob.google.com）
- App Store Connect でアプリが審査済みまたは準備完了であること
- デベロッパーウェブサイトのURLが確定していること

---

## ステップ1: デベロッパーウェブサイトがApp Store掲載情報に登録されているか確認

### 確認手順

1. **App Store Connect**（https://appstoreconnect.apple.com）にログイン
2. **マイApp** → `Nanikiru（myBabyOOTD）`を選択
3. **App情報**（左上タブ）をクリック
4. **一般情報**セクションを確認
   - [ ] **マーケティングURL** にデベロッパーウェブサイトのURLが入力されている
   - 例: `https://example.com` または `https://www.example.com`

> ⚠️ **重要**: ここにURLが未入力の場合、AdMobはapp-ads.txtを検出できません。先にURLを登録してください。

---

## ステップ2: AdMobでパブリッシャーIDスニペットを取得

### 確認手順

1. **AdMob**（https://admob.google.com）にログイン
2. 左サイドバー → **[アプリ]** をクリック
3. **[すべてのアプリを表示]** をクリック
4. 上部タブまたはリンク → **[app-ads.txt]** をクリック
5. `Nanikiru（myBabyOOTD）`の行を確認
6. **[app-ads.txtの設定方法]** をクリック
7. 以下を確認
   - [ ] **パーソナライズされたコードスニペット**が表示されている
   - [ ] コードスニペットに `pub-` から始まる**パブリッシャーID**が含まれている
   - [ ] コードスニペットをコピーしてテキストファイルに保存できる

> スニペットの形式例:
> ```
> google.com, pub-1810074247562384, DIRECT, f08c47fec0942fa0
> ```

---

## ステップ3: app-ads.txt ファイルを作成・確認

### 確認手順

1. テキストエディタ（メモ帳/テキストエディット）で `app-ads.txt` ファイルを開く
2. 以下を確認
   - [ ] ファイル名が正確に `app-ads.txt`（小文字、拡張子.txt）
   - [ ] ファイルの先頭にAdMobのコードスニペットが記載されている
   - [ ] コードスニペットに**自分のパブリッシャーID**（pub-で始まる）が含まれている
   - [ ] 余分な空白や改行がない（1行で記載）
   - [ ] ファイルの文字コードが **UTF-8** である

### ファイル内容の確認例

```
google.com, pub-1810074247562384, DIRECT, f08c47fec0942fa0
```

> ⚠️ 上記は例です。必ずAdMobからコピーした**自分のパブリッシャーID**を使用してください。

---

## ステップ4: app-ads.txt をウェブサイトのルートに配置

### 確認手順

1. ウェブサイトのルートディレクトリに `app-ads.txt` をアップロード済みか確認
2. ブラウザで以下のURLを開いてアクセスできることを確認
   - [ ] `https://example.com/app-ads.txt`（自分のドメインに置き換え）
   - [ ] ブラウザにファイルの内容（google.com, pub-..., DIRECT, ...）が**テキストとして表示**される

### 確認コマンド（ターミナル）

```bash
# 自分のドメインに置き換えて実行
curl -s https://example.com/app-ads.txt
# → google.com, pub-1810074247562384, DIRECT, f08c47fec0942fa0
# のように表示されればOK
```

> ⚠️ **404エラー**や**HTMLページが表示**される場合は、配置場所が間違っています。

---

## ステップ5: AdMobでステータスを確認

### 確認手順

1. **AdMob**（https://admob.google.com）にログイン
2. 左サイドバー → **[アプリ]** → **[すべてのアプリを表示]**
3. **[app-ads.txt]** タブをクリック
4. `Nanikiru（myBabyOOTD）`の行を確認

### 確認項目

| ステータス | 意味 | 対応 |
|-----------|------|------|
| ✅ **検証済み** | 完了。広告収益に影響なし | なし（正常） |
| ⚠️ **見つからない** | ファイル未検出 | ステップ4を再確認、24時間待つ |
| ⚠️ **検証されない** | ファイルは見つかったが内容が不正 | パブリッシャーIDを再確認 |

- [ ] ステータスが **「検証済み」** になっている

> ⚠️ App Storeの掲載情報を更新した場合、AdMobが検出するまで**最大24時間**かかります。

---

## ステップ6: クロールを強制更新（必要な場合）

### 手順（ステータスが未検証の場合）

1. AdMob → **[アプリ]** → **[app-ads.txt]**
2. `Nanikiru（myBabyOOTD）`の行で **[開く]** をクリック
3. **[アップデートを確認]** をクリック
4. 以下を確認
   - [ ] 「クロールをリクエストしました」等のメッセージが表示される
   - [ ] 同じ app-ads.txt を共有する全アプリのステータスが更新される

> ⚠️ **注意**: 「アップデートを確認」ボタンは使用できない場合があります。その場合は24時間待ってから再度確認してください。

---

## ステップ7: 広告実装コードの確認（アプリ側）

### Info.plist の確認

1. Xcode でプロジェクトを開く
2. `Info.plist` を開く
3. 以下を確認
   - [ ] **GADApplicationIdentifier** キーが存在する
   - [ ] 値にAdMobのアプリID（`ca-app-pub-...`）が正しく設定されている

### AdBannerView.swift の確認

4. `Views/Ads/AdBannerView.swift` を開く
5. 以下を確認
   - [ ] `AdConfig.bannerAdUnitId` に正しい**バナー広告ユニットID**（`ca-app-pub-.../...`）が設定されている
   - [ ] `SubscriptionManager.isAdsRemoved` が正しく動作している（プレミアム購入時に広告非表示）

## トラブルシューティング

### app-ads.txtが「見つからない」の場合

| 原因 | 確認方法 | 対応 |
|------|---------|------|
| App StoreのマーケティングURL未設定 | App Store Connectで確認 | URLを設定して24時間待つ |
| ファイルがルートに配置されていない | `curl`で確認 | ルート（/app-ads.txt）に配置 |
| パブリッシャーIDが間違っている | AdMobのスニペットと照合 | 正しいIDを再コピー |
| ファイル名が違う | ファイル名確認 | `app-ads.txt`（小文字）に変更 |
| まだクロールされていない | AdMobで確認 | 最大24時間待つ |

### 広告が表示されない（app-ads.txt以外の原因）

| 原因 | 確認方法 |
|------|---------|
| プレミアム購入済み | `SubscriptionManager.isPremium` を確認 |
| テストデバイス未登録（DEBUG） | `AdBannerView.swift` の `testDeviceIdentifiers` を確認 |
| AdMob SDK未導入 | `Package.resolved` または `Package.swift` を確認 |
| バナー広告ユニットIDが間違い | AdMob管理画面で確認 |
| ネットワーク不通 | 端末のネットワーク接続確認 |

---

## 完了定義

以下すべてにチェックが入れば完了です。

- [ ] App Store Connect の**マーケティングURL**にデベロッパーウェブサイトを登録済み
- [ ] AdMobから**パーソナライズされたコードスニペット**を取得済み
- [ ] `app-ads.txt` ファイルを作成し、正しいパブリッシャーIDを記載済み
- [ ] `https://自分のドメイン.com/app-ads.txt` でファイル内容がブラウザに表示される
- [ ] AdMobの **[app-ads.txt]** 画面でステータスが **「検証済み」**
- [ ] Xcodeの `Info.plist` に `GADApplicationIdentifier` が設定済み
- [ ] `AdBannerView.swift` の `bannerAdUnitId` が正しい
