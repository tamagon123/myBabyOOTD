# 乳児服装共有SNSアプリ（Nanikiru）要件定義書

## 1. 概要

### 1.1 アプリの目的・コンセプト

本アプリは、乳児期（特に0〜2歳児）の子供を持つ親が「今日の気温や天気に合わせた子供の服装選び」の悩みを解決するための写真共有型SNSです。テキストによるコミュニケーション（コメント機能・ダイレクトメッセージ）を完全に排除し、「服装の参考情報」を検索・共有することに特化することで、育児中の親が安心して利用できるセーフティな環境を提供します。

さらに、日々の服装・気温・天気を記録できる「カレンダー（育児日記）」機能、ベビー・キッズ用品の購入を支援する「買い物」機能を備え、服装選びの参考から記録・購入までを一貫してサポートします。

### 1.2 ターゲットユーザー

- 乳児（0歳〜2歳児前後）の子供を育てる保護者
- 日々の気候（気温・天気）や子供の成長（月齢・サイズ）に合わせた最適なコーディネートの具体例を手軽に検索したいユーザー
- コメント機能なしで、画像中心のSNSを望むユーザー

### 1.3 プラットフォーム

| 項目 | 内容 |
|------|------|
| クライアント | iOS 16+（Swift / SwiftUI） |
| バックエンド | Firebase（BaaS） |
| 認証 | Firebase Authentication |
| データベース | Firebase Firestore |
| 画像ストレージ | Firebase Storage |
| プッシュ通知 | Firebase Cloud Messaging |
| 課金 | StoreKit 2（買い切り型プレミアムプラン） |
| 広告 | Google AdMob（バナー広告） |
| トラッキング | App Tracking Transparency（ATT）による許可取得 |
| フォント | カスタムフォント（M PLUS 1p）をシステムフォントに適用 |

## 2. 機能要件

### 2.1 アカウント・認証機能

#### 2.1.1 サインアップ・ログイン方式

| 方式 | 概要 |
|------|------|
| メール・パスワード | メールアドレスとパスワードによるアカウント作成・ログイン |
| Google Sign-In | GoogleアカウントによるOAuth認証 |
| Sign in with Apple | Apple IDによるOAuth認証（nonceによるリプレイ攻撃対策） |

#### 2.1.2 プロフィール設定（初回登録）

初回ログイン後、以下のプロフィール情報を設定する画面を表示する。

| 項目 | 必須 | 内容 |
|------|------|------|
| ユーザーID（@xxx） | 任意 | 一意の表示ID。重複チェックあり。未設定でも利用可能 |
| 表示名 | 必須 | 画面上に表示される名前 |
| アバター | 必須 | 運営が用意したイラスト（Assets内7種類）または絵文字（20種類）から選択。個人写真アップロードは不可 |
| アバター背景色 | 任意 | HEXカラーコードで指定 |
| 地域（都道府県） | 必須 | 47都道府県のPicker選択 |
| 子供情報 | 必須 | ニックネーム・生年月日・性別。複数子供登録可能 |

※ 日記リマインダー通知（ON/OFF・通知時刻）は設定画面から後から変更可能（デフォルトOFF・21:00）。

#### 2.1.3 アカウント管理

- **ログアウト**: セッション破棄。自動ログインON/OFF設定可能
- **アカウント削除**: 再認証（パスワード/Google再ログイン）後、Firestoreデータ・Authアカウント・Storage画像を完全削除
- **パスワードリセット**: メールによるリセットリンク送信

### 2.2 投稿機能

#### 2.2.1 写真投稿

| 項目 | 仕様 |
|------|------|
| 写真枚数 | 正面（フロント）と背面（バック）の最大2枚。1枚のみでも投稿可 |
| 写真選択 | カメラ撮影またはフォトライブラリから選択 |
| 写真編集 | スタンプ貼り付け（Assets内9種類）。位置・拡大縮小・回転に対応し、Firestoreに保存して再編集時に復元 |
| EXIF除去 | アップロード時にGPS・撮影機器情報などのメタデータを自動削除 |
| 画像リサイズ | 長辺1200px以下に縮小後、JPEG品質85%で圧縮 |
| 公開設定 | 投稿を公開／非公開で保存可能 |

#### 2.2.2 服装メタデータ入力

| 項目 | 入力方式 |
|------|----------|
| 地域 | 都道府県Picker（47都道府県） |
| 性別 | 男の子 / 女の子 / その他 / 未選択 |
| 月齢 | 子供の生年月日から自動計算（Firestore保存時に月数化） |
| 天気 | 晴れ / くもり / 雨 / 雪（アイコン＋文字） |
| 気温 | 最高気温・最低気温を数値入力（手動または自動取得） |
| 服装ポイント | 自由記述テキスト（説明文） |

#### 2.2.3 アイテム（洋服）登録

| 項目 | 内容 |
|------|------|
| カテゴリ | トップス / ボトムス / アクセサリー / アウター / シューズ / スタイ / その他 |
| ブランド | 350種類以上のブランドマスターから選択＋自由入力可。ふりがな検索対応 |
| サイズ | 50, 60, 70, 80, 90, 100, 110, 120, フリー（cm） |
| タグ付け | 写真上にアイテムタグをドラッグ配置（x_ratio/y_ratioの比率座標） |

#### 2.2.4 天気自動連携

- Open-Meteo APIを使用して、選択した都道府県の当日の最高気温・最低気温・天気を自動取得
- 取得後、ユーザーが手動で修正可能
- 気温帯カテゴリ（〜9℃ / 10〜14℃ / 15〜19℃ / 20〜24℃ / 25℃〜）を自動算出

#### 2.2.5 下書き保存

- 投稿内容をUserDefaultsにJSON形式でローカル保存
- 画像はDocumentsフォルダにファイル保存（パス文字列で参照）
- 下書き一覧から選択して投稿を再開可能

### 2.3 タイムライン機能

#### 2.3.1 タブ構成

| タブ | 表示内容 |
|------|----------|
| 新着 | 全ユーザーの投稿を新着順に表示 |
| おすすめ | ログインユーザーの子供の月齢±3ヶ月・同一地域の投稿を優先表示 |
| フォロー中 | フォローしているユーザーの投稿のみを新着順に表示 |

#### 2.3.2 タイムライン表示

- **リスト表示**: 投稿カード（写真・ユーザー情報・いいね・天気・気温・説明文・アイテムリスト・アフィリエイトリンク）
- **グリッド表示**: 3列のミニカード（写真＋いいねボタン）
- **無限スクロール**: 最下部までスクロールで次ページ（20件ずつ）を自動取得
- **Pull-to-refresh**: 下に引っ張って最新投稿を取得
- **投稿者情報付加**: タイムライン取得時に、各投稿者のアバター・表示名・子供名を並列で取得して表示

### 2.4 検索機能

#### 2.4.1 検索条件（複数選択可・OR検索）

| 条件 | 入力方式 | 複数選択 |
|------|----------|----------|
| 地域 | 都道府県Picker | 可 |
| 性別 | チップボタン（男の子/女の子/その他） | 可 |
| 天気 | チップボタン（晴れ/くもり/雨/雪） | 可 |
| 気温帯 | チップボタン（5段階） | 可 |
| ブランド | テキスト自由入力＋ブランド検索シート | 可（自由入力＋選択のOR） |
| サイズ | 横並びチップボタン（50〜120, フリー） | 可 |

#### 2.4.2 ブランド検索シート

- 350種類以上のブランドをふりがな（カタカナ読み）付きで一覧表示
- ふりがな検索：ひらがな→カタカナ自動変換、大文字→小文字、記号正規化
- 選択したブランドは検索条件に追加される

### 2.5 リアクション・フォロー機能

#### 2.5.1 いいね

- ハートアイコンをタップしていいね・取消をトグル
- いいねした投稿のIDを`likes`コレクションに保存
- `likes_count`をリアルタイムで増減

#### 2.5.2 フォロー

- 他ユーザーのプロフィール画面からフォロー・フォロー解除
- `follows`コレクションにフォロー関係を保存
- フォロワー数は`users`ドキュメントに集計保持
- フォロー中一覧は設定画面から閲覧可能（タップでそのユーザーの投稿一覧へ）
- フォロワー一覧は非表示（セーフティ対策）

#### 2.5.3 ブロック

- 他ユーザーのプロフィール画面からブロック・ブロック解除
- `blocks`コレクションにブロック関係を保存（blocker_id, blocked_id）
- ブロックされたユーザーの投稿はタイムラインに表示されない（クライアント側フィルタリング）
- ブロックしたユーザー一覧は「ブロックリスト画面」から管理可能

### 2.6 モデレーション機能

#### 2.6.1 通報

- 各投稿に通報ボタンを配置
- 同一ユーザーによる重複通報を防止
- `reports`コレクションに通報レコードを保存
- `reports_count`が5件以上になると自動的に`is_hidden=true`となり、タイムラインから非表示

### 2.7 プレミアム機能（買い切り）

| 項目 | 内容 |
|------|------|
| 機能 | ① 広告非表示（AdMobバナー）／② カレンダー編集期間拡張（無料:1日前まで、有料:365日前まで） |
| 購入 | App Store経由の買い切り型課金（StoreKit 2） |
| 状態保存 | UserDefaults `premium_isPurchased` に永続化 |
| 復元 | 購入履歴の復元機能（AppStore.sync() → currentEntitlementsで検証） |
| 商品ID | `com.tamagon.Nanikiru.premium` |

### 2.8 アフィリエイト機能

- 投稿に登録されたブランド名から、楽天市場・Amazonの商品検索リンクを動的生成
- アフィリエイトID未設定時は通常の検索URL（動作確認用）
- 投稿詳細画面にアフィリエイトカードを表示
- ブランド別最適ASPマッピング（ファストファッション→Amazon、子供服ブランド→楽天等）
- Firestoreからのアフィリエイトリンク設定優先（動的更新対応）

### 2.9 カレンダー（育児日記）機能

| 項目 | 内容 |
|------|------|
| 目的 | 日々の服装・気温・天気を記録し、後から振り返りや参考にできる |
| 表示 | 月間カレンダー（曜日別に投稿・日記を表示） |
| エントリー | コメント・天気・気温・写真を記録（公開/非公開設定可） |
| 天気連携 | 当日の天気・気温を自動取得（過去日はHistorical API、未来はForecast API） |
| プレミアム制限 | 無課金：前日まで編集可／有課金：1年前まで編集可 |
| カレンダー投稿 | カレンダーからの投稿はタイムラインに表示せず、日記として記録 |
| 公開カレンダー | 他ユーザーの公開カレンダーを閲覧可能 |

### 2.10 買い物機能

| 項目 | 内容 |
|------|------|
| 目的 | ベビー・キッズ用品の購入をサポート |
| 表示 | ショッピングポータル一覧（Amazon、楽天、しまむら等） |
| データソース | Firestore `shopping_portals` コレクションから動的取得 |
| アフィリエイト | 各ポータルのURLはアフィリエイトリンク対応 |

### 2.11 通知機能

| 項目 | 内容 |
|------|------|
| プッシュ通知 | FCM経由でフォロー・いいね・新規投稿通知を配信 |
| 通知履歴 | アプリ内で通知一覧を表示（未読バッジ対応） |
| 既読管理 | 通知タップまたは画面表示で自動既読化 |
| 一括削除 | 全通知の一括削除機能 |
| 日記リマインダー | 設定時刻（デフォルト21:00）に日記記録を促す通知（ON/OFF可） |

### 2.12 広告・ATT機能

| 項目 | 内容 |
|------|------|
| 広告表示 | AdMobバナー広告（プレミアム購入で非表示） |
| ATT対応 | AppTrackingTransparencyフレームワークでトラッキング許可取得 |
| 取得タイミング | アプリがactive状態になってから1秒遅延で表示（シーン対応） |
| 未設定時の動作 | 未許可時でも広告は表示される（ターゲティング精度が低下） |

## 3. 非機能要件

### 3.1 セキュリティ

| 項目 | 対応内容 |
|------|----------|
| EXIFデータ除去 | 画像アップロード時にGPS・撮影機器情報などのメタデータを完全削除 |
| 個人情報保護 | アバターはイラスト/絵文字のみ。個人写真アップロード不可 |
| 再認証 | アカウント削除前にパスワードまたはGoogle/Apple再認証を要求 |
| 通報非表示 | 5回通報で自動非表示（悪質投稿対策）
| ブロック | 特定ユーザーの投稿を非表示に設定（セーフティ対策） |
| 匿名性 | コメント機能なし。いいねのみのリアクション |

### 3.2 パフォーマンス

| 項目 | 目標値 |
|------|--------|
| タイムライン初回表示 | 2秒以内（Firestoreクエリ＋並列enrich） |
| 画像読み込み | キャッシュ活用。非同期読み込みでUIブロックなし |
| 無限スクロール | 最下部到達時に次20件を取得。読み込みインジケータ表示 |
| Firestoreキャッシュ | 100MBのオフライン永続化。通信節約・オフライン対応 |

### 3.3 可用性・運用

| 項目 | 内容 |
|------|------|
| オフライン対応 | Firestoreのオフライン永続化により、既読データはオフラインで閲覧可能 |
| バックアップ | Firestore・StorageはFirebase管理による自動バックアップ |
| ブランドマスター拡張 | Firestore `brands`コレクションで管理（アプリ起動時に取得）。クライアント側の静的配列はフォールバックとして保持 |

### 3.4 プライバシー

- コメント機能・ダイレクトメッセージ機能は非搭載
- フォロワー一覧は非表示（トラブル防止）
- 通報したユーザーの情報は運営のみ閲覧可能

## 4. UI/UX要件

### 4.1 デザイン方針

- **生成り（écru）ベース**: 優しい生成り色（`#F5EDDC`相当）を背景色として使用。目に優しい印象
- **朱色アクセント**: メインCTA・タブ選択に朱色（`#D12114`相当）を使用
- **グラデーション不使用**: フラットデザインで統一
- **カードUI**: プロフィールヘッダーなどは白背景カード＋角丸＋影でリッチ感を演出
- **カスタムフォント**: M PLUS 1pをシステムフォントに適用（Swizzle技術によるグローバル置換）

| Amazon | アフィリエイトリンク | Firestore設定優先、未設定時は通常検索URL |

## 6. 用語定義

| 用語 | 説明 |
|------|------|
| Nanikiru | アプリ名。子供の服装選びの悩みを解決するSNS |
| Post（投稿） | ユーザーが投稿したコーディネート1件。写真＋メタデータ＋アイテムリスト |
| Item（アイテム） | 投稿に紐づく洋服1点。ブランド・サイズ・カテゴリ情報を持つ |
| ItemTag | 写真上に配置されるアイテムの位置情報（比率座標） |
| Draft（下書き） | 投稿前にローカル保存された一時データ |
| Enrich | タイムライン取得時に、生の投稿データに投稿者情報を付加する処理 |
| 月齢 | 子供の生年月日から投稿時点までの月数。検索・おすすめ表示に使用 |
| temp_category | 平均気温から算出される気温帯キー（"0-9" / "10-14" / "15-19" / "20-24" / "25-"） |
