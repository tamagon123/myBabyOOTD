# Documents フォルダ ガイド

このフォルダには、プロジェクトの設計書・手順書・管理資料が置かれています。

---

## どの手順書を見ればいいか？

| やりたいこと | 見るファイル |
|---|---|
| **開発環境を最初から構築する** | [開発環境セットアップ.md](開発環境セットアップ.md) |
| **コードの構造・フローを理解する** | [基本設計.md](基本設計.md) |
| **アプリの機能要件を確認する** | [要件定義.md](要件定義.md) |
| **テスト項目を確認する** | [テスト仕様書.md](テスト仕様書.md) |
| **買い物タブのリンクを更新する** | [ブランド・アフィリエイト管理手順書.md](ブランド・アフィリエイト管理手順書.md) |
| **残りの実装タスクを確認する** | [未実装・必須改修・今後対応一覧.md](未実装・必須改修・今後対応一覧.md) |
| **アプリの画面遷移・全体フローを確認する** | [application_flow_document.txt](application_flow_document.txt) |

## 古い・重複したファイルについて

`archive/` フォルダに移動したファイルは、過去のバージョンや重複ファイルです。通常は参照不要です。
