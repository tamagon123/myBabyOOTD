# ブランド・アフィリエイト管理手順書

## 概要

アプリ内で使用する**ブランド名**、**買い物タブの入口リンク**、**アフィリエイトID**は、Firebase Firestore で動的に管理されています。

Firebase Console 上で編集することで、**アプリの更新・審査なし**に変更を全ユーザーに即時反映できます。

---

## 前提条件

- Firebase プロジェクト `myBabyOOTD` への管理者アクセス権
- [Firebase Console](https://console.firebase.google.com) にログイン済み

## 1. ブランド名の追加・編集

### コレクション: `brands`

投稿や検索で選択できるブランド名を管理します。

### 1.1 Firebase Console へアクセス

1. [Firebase Console](https://console.firebase.google.com) を開く
2. プロジェクト `myBabyOOTD` を選択
3. 左メニュー → **Firestore Database** → **データ** タブ

### 1.2 既存ブランドの確認

`brands` コレクションを展開し、既存ドキュメントを確認できます。

### 1.3 新規ブランドを追加

1. `brands` コレクションの横の **「ドキュメントを追加」** をクリック
2. ドキュメントID を入力（例: `petitmain`）または **「自動ID」** を選択
3. 以下のフィールドを追加：

| フィールド | 型 | 必須 | 説明 | 例 |
|---|---|---|---|---|
| `name` | String | ○ | ブランド表示名 | `petit main` |
| `reading` | String | ○ | カタカナ読み（ふりがな検索用） | `プチマイン` |
| `order` | Number | ○ | 表示順（小さいほど上に表示） | `50` |
| `isActive` | boolean | ○ | `true` で表示、`false` で非表示 | `true` |

4. **保存** をクリック

### 1.4 ブランド名を編集・削除

- **編集**: 既存ドキュメントを開き、フィールドの値を修正 → **更新**
- **非表示にする**: `isActive` を `false` に変更（削除せず非表示にできる）
- **削除**: ドキュメントを開き → 右上の **「削除」** アイコン → 確認

## 2. 買い物タブの入口リンクの追加・編集

### コレクション: `shopping_portals`

買い物タブに表示される各ショッピングサイトへのリンクを管理します。

### 2.1 新規リンクを追加

1. `shopping_portals` コレクションの横の **「ドキュメントを追加」** をクリック
2. 以下のフィールドを追加：

| フィールド | 型 | 必須 | 説明 | 例 |
|---|---|---|---|---|
| `title` | String | ○ | タイトル（買い物タブに表示） | `楽天 ベビー・キッズ` |
| `description` | String | ○ | 説明文 | `ポイント還元率が高い...` |
| `url` | String | ○ | 遷移先URL（アフィリエイトURL可） | `https://hb.afl.rakuten.co.jp/...` |
| `platform` | String | ○ | `rakuten` / `amazon` / `other` | `rakuten` |
| `category` | String | ○ | カテゴリ名（`ShoppingCategory` と一致） | `ベビー用品` |
| `badge` | String | - | バッジ文言（任意） | `おすすめ` |
| `order` | Number | ○ | 表示順（小さいほど上） | `0` |
| `isActive` | boolean | ○ | `true` で表示 | `true` |

### 2.2 カテゴリ名の選択肢

以下の文字列を `category` に指定してください：

- `すべて`（`order` を小さくして最初に表示する場合）
- `ベビー服`
- `キッズ服`
- `靴`
- `おもちゃ`
- `ベビー用品`
- `マタニティ`

※ 買い物タブの「すべて」フィルタ選択時は、すべての `isActive: true` のリンクが表示されます。

### 2.3 通常URL → アフィリエイトURLに変更

既存ドキュメントを開き、`url` フィールドの値をアフィリエイトURLに書き換えるだけです。

## 3. 共通アフィリエイトIDの設定

### ドキュメント: `config/affiliate`

各プラットフォーム（楽天・Amazon等）の**共通アフィリエイトID**を設定します。

ここにIDを設定すると、**自動生成されるすべての検索リンク**にアフィリエイトパラメータが付きます。

### 3.1 ドキュメントを作成・編集

1. `config` コレクション → `affiliate` ドキュメントを開く
2. なければ **「ドキュメントを追加」** で `affiliate` という名前を指定して作成
3. 以下のフィールドを追加：

| フィールド | 型 | 必須 | 説明 | 例 |
|---|---|---|---|---|
| `rakutenId` | String | - | 楽天アフィリエイトID | `1a2b3c4d...` |
| `amazonTag` | String | - | Amazon アソシエイトタグ | `yourtag-22` |
| `linkshareId` | String | - | リンクシェア ID | `12345` |
| `valuecommercePid` | String | - | バリューコマース pid | `xxxx` |
| `valuecommerceSid` | String | - | バリューコマース sid | `yyyy` |
| `a8AffiliateId` | String | - | a8.net アフィリエイトID | `a8mat=...` |

### 3.2 空のままでも動作します

未設定のフィールドは空文字として扱われ、**通常の検索リンク**が生成されます。

## 4. ブランド別カスタムアフィリエイトURLの設定

### コレクション: `affiliate_links`

特定のブランドを特定のECサイトの**専用アフィリエイトURL**に遷移させたい場合に使用します。

（例: ミキハウス → 楽天のミキハウス公式ページへ直接遷移）

### 4.1 新規設定を追加

1. `affiliate_links` コレクションの横の **「ドキュメントを追加」** をクリック
2. ドキュメントID を手動入力（例: `mikihouse_rakuten`）または自動ID
3. 以下のフィールドを追加：

| フィールド | 型 | 必須 | 説明 | 例 |
|---|---|---|---|---|
| `brandName` | String | ○ | ブランド名（`brands` の `name` と一致） | `mikihouse` |
| `platform` | String | ○ | `rakuten` / `amazon` / `linkshare` / `valuecommerce` / `a8net` | `rakuten` |
| `url` | String | ○ | 完全なアフィリエイトURL | `https://hb.afl.rakuten.co.jp/...` |
| `isActive` | boolean | ○ | `true` で有効 | `true` |

### 4.2 優先順位

1. `affiliate_links` に該当ブランドのURLが登録されていれば → **そのURLを直接使用**
2. 未登録の場合 → 共通アフィリエイトID付きの**自動生成リンク**を使用
3. 共通IDも未設定の場合 → **通常の検索リンク**を使用

## 5. 反映タイミング

| 操作 | 反映されるタイミング |
|---|---|
| Firestore でドキュメントを保存 | アプリの**次回起動時**または**MainTabViewのonAppear時**に取得 |
| ユーザーがアプリを再起動しない場合 | 別タブに移動して戻ると、最新データが取得される場合があります |

### 即時反映を確認したい場合

1. アプリを一旦終了
2. 再度アプリを開く
3. 買い物タブやブランド検索で変更が反映されていることを確認

---

## 補足: 初回移行時の注意

アプリ初回リリース時、`brands` コレクションが空の場合、**ソース内のローカルブランド一覧（375件）**がフォールバックとして使用されます。

Firestore にブランドデータを移行する場合は、開発者に `BrandService.uploadDefaultBrands()` を実行してもらってください。
