# Nanikiru（myBabyOOTD）リリース前テスト仕様書

## 1. テスト概要

- **アプリ名**: Nanikiru（myBabyOOTD）
- **プラットフォーム**: iOS（SwiftUI）
- **対象バージョン**: リリース初版
- **テスト目的**: アプリリリース前に全機能の動作確認、品質保証
- **テスト観点**: 機能テスト、UI/UXテスト、エラーハンドリング、データ整合性、セキュリティ

---

## 2. テスト環境

| 項目 | 内容 |
|------|------|
| テスト端末 | iPhone 実機（複数機種推奨）+ Simulator |
| OS バージョン | iOS 15.0 以上（ATT機能はiOS 14.5+） |
| ネットワーク | Wi-Fi / モバイルデータ / オフライン |
| Firebase環境 | 本番環境（またはステージング） |
| テストアカウント | 複数アカウント（メール・Google・Apple各1つ以上） |

## 5. デグレ・回帰テスト観点

リリース前に以下の観点で回帰テストを実施:

1. **認証フロー**: ログイン→プロフィール設定→メイン画面の一連の流れ
2. **投稿フロー**: 新規投稿作成→タイムライン表示→いいね→削除
3. **検索フロー**: 条件設定→検索実行→結果確認→投稿詳細
4. **カレンダーフロー**: カレンダー表示→日記作成→天気取得→保存→公開カレンダー閲覧
5. **買い物流ロー**: 買い物タブ→ポータル表示→タップ→Safari遷移
6. **プレミアムフロー**: 設定→プレミアム購入→広告非表示確認→カレンダー編集期間拡張確認
7. **通知フロー**: 通知受信→通知一覧→タップ遷移→一括削除
8. **ブロックフロー**: プロフィール→ブロック→タイムライン非表示確認→ブロック解除
9. **設定フロー**: プロフィール編集→下書き確認→通知設定→ログアウト→再ログイン
10. **フォローフロー**: フォロー→フォロー中タブ→フォロー解除
