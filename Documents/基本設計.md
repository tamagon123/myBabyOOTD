## 5. 認証設計

### 5.1 認証フロー

#### メール・パスワード認証

```
1. AuthView → email/password入力
2. AuthViewModel.signInWithEmail()
   → FirebaseAuth.signIn()
   → Firestore users/{uid} を取得
   → 新規 → 最小限のAppUserを作成・保存
   → isSignedIn = true
```

#### Google Sign-In

```
1. GIDSignIn.signIn() でGoogle認証
2. GoogleAuthProvider.credential でFirebase Credential作成
3. FirebaseAuth.signIn(with: credential)
4. Firestore users/{uid} 新規/既存判定
```

#### Sign in with Apple

```
1. prepareSignInWithApple() → nonce生成・SHA256ハッシュ化
2. SignInWithAppleButton → Apple認証
3. handleSignInWithApple() → identityToken + rawNonce でCredential作成
4. FirebaseAuth.signIn() → 新規/既存判定
```

### 5.2 自動ログイン設定

- `UserDefaults` の `autoLogin` キーで永続化（デフォルトtrue）
- `false` の場合、アプリ起動時にFirebaseセッションがあっても強制サインアウト

## 6. 投稿設計

### 6.1 新規投稿フロー

```
1. NewPostView起動（フルスクリーンシート）
2. 写真選択（front/back）
   ├─ カメラ撮影 or ライブラリ選択
   ├─ UIImagePickerController（ソースタイプ切り替え）
   └─ スタンプ編集（PhotoEditor風カスタム実装）
3. アイテム登録
   ├─ デフォルト3件（トップス・ボトムス・アクセサリー）
   ├─ カテゴリPicker
   ├─ ブランド検索（BrandSearchSheet：ふりがな検索対応）
   ├─ サイズ選択（チップボタン）
   └─ タグ付け（写真上にドラッグ配置）
4. 天気情報
   ├─ 地域Picker選択
   ├─ 天気自動取得ボタン → WeatherService.fetch()
   └─ 手動修正可
5. 投稿 or 下書き保存
   ├─ 投稿 → uploadPost() → Storage画像アップロード → Firestore保存
   └─ 下書き → DraftManager.saveDraft()
```

### 6.2 画像アップロード設計

| 処理 | 内容 |
|------|------|
| リサイズ | 長辺1200px以下に縮小（UIGraphicsImageRenderer） |
| EXIF除去 | CGImageDestinationでメタデータを空辞書に置換 |
| 圧縮 | JPEG品質85% |
| Storageパス | `posts/{postId}/front.jpg`, `posts/{postId}/back.jpg` |
| 並列アップロード | front/backを順次アップロード |

### 6.3 下書き設計

| 項目 | 内容 |
|------|------|
| 保存先 | UserDefaults（JSON形式） |
| 画像保存 | Documentsフォルダにファイル保存。下書きデータにはパス文字列を保持 |
| 構造 | PostDraft（description, regionIndex, weatherType, tempMax/Min, items, frontImagePath, backImagePath, savedAt） |
| 一覧 | DraftListViewで日時降順表示。スワイプ削除対応 |
| 再開 | 選択時にDraftManager.pendingDraftにセット → MainTabViewが監視 → NewPostView自動表示 |

```swift
  .order(by: "created_at", descending: true)
  .limit(to: 20)
```

### 7.2 Enrich処理（投稿者情報付加）

```
1. 投稿リストから重複なしuser_id一覧を抽出
2. withTaskGroupで各user_idのFirestore usersドキュメントを並列取得
3. userMapに蓄積（avatarId, displayName, children等）
4. 各PostにposterAvatarId / posterDisplayName / posterChildAgeName を設定
```

```swift
// → DragGesture座標 = 画像左上 (0,0) と完全一致
```
